Logger Code Reference
=====================

How To Read
- First two digits = module.
- Remaining digits = local issue code inside that module.
- Read the log line, look up the code here, then apply the short fix.

Module Key
- `00` Main lifecycle, startup, shutdown, testing, and dependency bootstrap surface.
- `01` DatabaseManager
- `02` BatchManager
- `03` QueueManager
- `04` CrashHandler
- `05` HttpExecutor
- `06` NetworkConfig
- `07` NetworkManager
- `08` NetworkRequest
- `09` NetworkWorker
- `10` RateLimiterRegistry
- `11` FileTaskRegistry
- `12` TaskExecutor
- `13` TaskScheduler

Notes
- `DependencyManager` does not emit direct logger warn/error codes; dependency bootstrap failures surface through `0004`.
- Exception classes are intentionally excluded from this map because they wrap or forward existing failures rather than identify subsystem-specific fixes.
